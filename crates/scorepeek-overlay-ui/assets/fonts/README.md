- Source: https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/oxanium

- License: SIL Open Font License 1.1, preserved in `OFL.txt`.

Native registers these bytes alongside system fonts; OBS serves the same bytes from the
executable. No runtime download or host font installation is required.
