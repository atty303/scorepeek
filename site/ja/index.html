Technical principles

ゲームから独立。表示からも独立。

ゲームの内部データに依存せず、画面から認識して記録。認識と表示を分離した設計で、柔軟な拡張が可能です。

Game screen ゲームの内部データは必要ありません。
→
Recognition 画面からリザルトを認識します。
→
Event API / SQLite スコアと履歴をローカルに保存。
→
Overlays & tools さまざまな表示toolにつなげられます。
