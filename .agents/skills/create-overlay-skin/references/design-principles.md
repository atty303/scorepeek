# デザイン原則

本資料は2026-09-08に利用者と合意した新規スキン制作・再設計の判断基準。
ゲームの事実ではなく、scorepeekのデザイン上の選択である。
既存masterの原典と再現手段は `docs/design/overlay-canvas/README.md` を参照する。masterは世界観と情報設計の原典であり、
package previewそのものではない。package previewはskill本体の共通sceneから実装済みskinを描画して生成する。

## 世界観と再現

- 情報の意味、グループ、優先順位を保つ。配置、余白、比率は読みやすさを検証して変えてよい。
- 採用見本の素材感、輪郭、文字の階層、密度を原典にする。フレームを単純な線に、金属文字をベタ塗りにする等の実装都合の簡略化をしない。
- 固定角と辺、面、縁、反射、溝などを見本に応じて分解する。画像、CSS、SVG、atlasは手段であり、特定の手段の少なさを品質指標にしない。
- リッチさを装飾量だけで作らない。素材の細部とスタイリッシュな動きを使い、大きく常時明滅するフレームや粒子でコンテンツを覆わない。
- canvasの隙間から見える背景にも中程度の大きさの素材変化を持たせる。ほぼ黒の面だけにせず、文字・枠・ゲーム映像を背景画像へ焼き込まない。
- emptyの内側はゲーム・SP/DP手元・顔・コメント等の利用者のコンテンツ用。任意title、無title、fill、S/M/Lの全条件で形と可読性を保つ。背景offも完成形として評価する。
- 装飾はwidget外へ出てよいがcanvas内でcropする。利用者がcanvasとwidget配置で調整する。自動paddingや保存済み配置の書換えを追加しない。

## 意味ごとの表現

| 項目 | 必須の扱い |
| --- | --- |
| 難易度種別 | BEGINNER緑、NORMAL青、HYPER黄、ANOTHER赤、LEGGENDARIA紫。色相を保つ。文字・badge背景・帯等は自由だが実寸で十分な識別面積を確保する。スキン色と衝突したら暗い地や縁などで分離する |
| SP/DP・レベル数値 | 種別とは別の情報として読めるようにする。種別だけから難しさや数値を推定しない |
| クリア状態 | 文字で明示する。色相は自由だが同一スキンのBEST・履歴等で意味対応を一貫させる。ランプや継続的な光は補助 |
| AAA | DJ LEVEL区分の最高として専用素材・縁・光などで明確に特別扱い。AAから単なる等間隔の強弱にしない |
| FULL COMBO | クリア区分の特別な到達点。AAAとは独立に素材・動きを設計し、共通の最高評価スタイルを強制しない |
| AA、A以下 | AAは上質な通常表現、A以下は控えめ。低ランクを警告、エラー、プレイヤーの能力判定にしない |
| EX SCORE | 桁を判別しやすく、値の変化で位置が不安定にならないようにする。実値は即座に更新。既存情報階層を維持する |
| ミス・コンボブレイク | ゼロも通常の補助数値。ゼロからFCを推測しない |
| PGREAT/GREAT/GOOD/BAD/POOR | PGREATだけ控えめなアクセント。桁とbaselineを揃える。低い判定へ警告点滅を付けない。色相は自由 |
| FAST/SLOW | 優劣のない対として同じ重み。色や配置で識別してよい。ゼロや一致にも演出を付けない |
| プレイオプション | 名前・組合せ・意味を保持する補助情報。内容による強調差、独自分類、略称による欠落を作らない |
| 履歴 | 最新行を強調しない。日時と順序で新旧を示し、列を比較できるようにする。AAA/FCの素材は小さくても維持する |
| グラフ | 線、凡例、軸の対応と単位・位置を保持。データ線の明滅・動く光・値を変える描画animationなし。素材は主に周辺へ |
| 曲名・artist | 通常フォントで曲名を主役、artistを控えめにする。文字列を変えず、世界観は主に周囲の素材で作る |
| SYSTEM/RESULT | ゲーム成績とは分離。正常は控えめ、errorは識別可能にする。AAA/FCの特別表現を流用しない。runtimeの既存意味・状態を変更しない |
| 未取得/不明 | 共通UIの中立表示を保つ。0、NO PLAY、FAILEDと区別し、独自の代替値を作らない |

色相の自由は「同じスキン内で同じ意味の規則が一貫する」ことを条件にする。
難易度種別はこの自由の明示的な例外。明度・彩度・反射は識別色相を失わない範囲で調整できる。

## 文字と動き

- 欧文の複数フォント、数字atlas、単語atlasを使ってよい。主要数値だけでなくラベルも素材を揃える。
- 日本語はsystem font。Notoなどの日本語fontを同梱・runtime downloadしない。和英混在曲名は通常text。
- atlasの透明余白とdescenderを含むbaseline、比例幅、数字の桁揃えを実寸で確認する。未知文字列は通常textで表示する。
- 実際の文字を意味のあるDOM textとして保持する。装飾はaccessibilityとhit testingから除外する。
- 表示状態の継続的な演出だけを作る。AAA/FCの装飾は過去の記録にも使えるが、新規達成を主張しない。
- 演出間のqueue・優先度調停を追加しない。面積、明度差、速度、位相などのデザインと同時表示検証で整える。
- 品質を優先し、負荷だけを理由に見本を簡略化しない。ただし既存のhidden/idle、native raster cap、browser frame-rate所有権は保持する。
